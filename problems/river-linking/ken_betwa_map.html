Officially both phases sit under the same 8-year/2030 project banner — but only Phase I has a foundation stone and visible construction. Phase II's individual approval and construction timeline isn't confirmed in any source we found, which makes it later in practice even though it isn't formally scheduled that way.

The current official technical total (908,428 ha) is ≈14.5% short of the press headline (1,062,000 ha) — real, but far smaller than an earlier pass through this analysis claimed (~62%, based on incomplete component data — corrected here using NWDA's own master table). Separately: the widely-cited 635,661 ha figure is a genuine original-DPR number, but it already ran ~23% ahead of that same DPR's own 515,210 ha command-area estimate — confirming SANDRP's 2017 objection using the government's own numbers.

What problem does this solve?

Most of this project's water never leaves the Ken basin: 4,050 MCM used directly within Ken (Damoh, Banda, Panna via lift schemes and pick-up weirs) against just 1,377 MCM diverted to Betwa — of which only 51 MCM actually arrives. The genuinely dry points (Shivpuri, Jhansi, Datia) sit off the physical canal entirely; their claimed benefit rides on Phase II structures with no confirmed timeline, on Betwa's own local tributaries. The "Ken-Betwa Link" name describes a small fraction of what the project actually does.

Caveats — read before citing
  • Rainfall ≠ streamflow; ERA5-based reanalysis has known accuracy limits in India, worse pre-2000.
  • Point samples, not watershed-averaged; canal path is straight-line, not the true engineered alignment; structure coordinates are approximate.
  • Bubble sizes use a square-root scale on hectares (area-proportional), not linear radius. Lalitpur is shown at fixed size (MCM release, not a command area).
  • Datia's primary drainage is the Sindh/Pahuj system, not Betwa/Orr — its inclusion as a Lower Orr beneficiary is itself contested.
  • Bina Complex is near "Chattarpur village," Sagar district — not Chhatarpur district on the canal route. Easy to confuse; kept deliberately distinct.
  • Kesari Barrage's command area and every Phase-II structure's environmental/social impact figures (except Lower Orr's) were not found in public sources — shown as unknown, not zero.
