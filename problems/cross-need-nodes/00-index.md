# Cross-Need Nodes — Register

A **node** is one policy object producing failures in two or more needs from `../tier-taxonomy.md`. Nodes are invisible from inside a single tier file and only surface once a tier is complete — check for them during the tier summary, and maintain this register across tiers, not per tier. See `CLAUDE.md` §"Cross-need nodes" for the definition and rules.

A node is worth more than a shortlist row: one intervention there propagates across needs.

- [Construction](02-construction.md) — air + water + shelter + sleep + food
