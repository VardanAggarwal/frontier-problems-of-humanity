# Construction

**Needs affected:** Tier 1 air (dust, demolition emissions) + water (sand mining, groundwater draw at sites) + shelter (build quality, informal housing stock) + sleep (noise, migrant labor schedules) + food (land conversion from agricultural use).

**Status:** No single regulator holds it — the node spans state PWDs, pollution control boards, labor departments and municipal building-plan authorities, none of which owns the full failure chain.

See tier files: `../tier-failure-history/tier1-physiological/03-air.md`, `02-water.md`, `04-shelter-thermoregulation.md`, `06-sleep-circadian.md`, `01-food.md` (paths relative to `tier1-physiological/`).
