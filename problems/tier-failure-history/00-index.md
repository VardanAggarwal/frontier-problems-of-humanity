# Tier Failure History — Topic Index

Documented history of how each need in `../tier-taxonomy.md` has been threatened, and how humanity built institutions/technologies/practices in response. One file per topic, researched independently to avoid single-mechanism collapse (the flaw in the original `../tier-failure-history.md` pass).

The machine-readable version of this list — ids, tier, order, definitions, per-file status — is **[`needs.yaml`](needs.yaml)**, which is the source of truth. This file is the human-readable view; keep the two in step.

**File status.** `standard` (unmarked) = written to the full invariant in `CLAUDE.md`, with `### Where it worked` and an India section. **`first-sweep`** = a first pass that does not yet meet the invariant; 26 of the 36 files are in this state, and none of them has a `### Where it worked` section, so none can yet answer whether activism or enterprise moves that need. A `first-sweep` file is not ready for `process-leaf`.

Each need file keeps its threat history, evolution, and `### Where it worked`. Per-instance analytic content (magnitude/denominator, who works it, the gap) now lives in **leaves** — `tierN-<tier>/<need>/<slug>.md`, one per documented failure. See `../schema.md` and `../data-model.yaml` for the leaf / actor / node / cross-cutting-leaf record types.
